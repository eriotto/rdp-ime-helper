# キー入力の手動テスト表

接続先は JIS 配列（`Layout File = KBD106.DLL`）を前提にしています。
メモ帳などで、IME オフの状態で試してください。

トレイのツールチップの「変換」欄で、どちらの表を使うかが決まります。

| ツールチップ | 使う表 |
|---|---|
| `変換：ON` | [A. 英語配列キーボード](#a-英語配列キーボード変換-on) |
| `変換：OFF（JISキーボード）` | [B. JIS キーボード](#b-jis-キーボード変換-off) |

## A. 英語配列キーボード（変換 ON）

「期待」は、キーの刻印どおりの文字です。

### キーリピート・Shift の確認

| 操作 | 期待 |
|---|---|
| Shift+`2` を押しっぱなし | `@@@@…` |
| Shift+`2` を押したまま Shift だけ離す | `@@@2222…`（途中から `2`） |
| `=` を押したまま Shift を押す | `===+++…`（途中から `+`） |
| 左右どちらの Shift でも | 同じ結果 |
| 上の操作のあとに `a` を打つ | 小文字の `a`（Shift が押しっぱなしになっていない） |

### 変換しないことの確認（ショートカット）

| 操作 | 期待 |
|---|---|
| Ctrl+`=`（ブラウザ） | 拡大 |
| Ctrl+`-`（ブラウザ） | 縮小 |
| Ctrl+`[` / Ctrl+`]`（VS Code） | インデント操作 |
| Alt+`` ` `` | 半角/全角として IME が切り替わる（既知の挙動） |

## C. Alt 単押し（キーボードを問わず）

| 操作 | 期待 | ログ |
|---|---|---|
| 左Alt 単押し | IME オフ（何度押してもオフのまま） | `Alt(Left): 単押し … → IME OFF` |
| 右Alt 単押し | IME オン（何度押してもオンのまま） | `Alt(Right): 単押し … → IME ON` |
| Alt を離したとき | メニューバーがアクティブにならない | — |
| Alt+Tab | 通常どおりウィンドウ切替。IME は変わらない | `取消（他キー …）` |
| Alt を 0.5 秒以上押してから離す | IME は変わらない | `対象外（長押し …）` |
| Shift を押したまま Alt 単押し | IME は変わらない | `対象外（Ctrl/Shift/Win併用）` |
| Alt を押したままクリック | IME は変わらない | `取消（マウスボタン）` |

## IME オンのときの注意

IME オン（ローマ字入力）では、記号は IME によって全角や別の記号に変わります。キーボードが JIS の場合と同じ動きなので、異常ではありません。

- `[` → `「`
- `-` → `ー`
- `~` → `～`
- `\` → `＼`
